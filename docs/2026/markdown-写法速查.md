## 基本写法

| 想写 | 写法 | 说明 |
|---|---|---|
| 二级标题 | `## 标题` | 文档页从 h2 起，h1 由 front matter 的 `title` 生成 |
| 强调 | `**粗**` `*斜*` | 中文之间不必加空格 |
| 行内码 | `` `docs/` `` | 会带浅底，字号缩小到 .86em |
| 代码块 | 三个反引号 + 语言名 | 语言名只影响高亮，不加也能渲染 |
| 链接 | `[文字](地址)` | 站内互链见下 |
| 图片 | `![](img/图.png)` | 相对 `docs/` 的路径，构建时原样复制 |
| 引用 | `> 一句` | 左侧一条竖线，文字降一级颜色 |
| 分隔线 | `---` | 单独一行，注意别和 front matter 混 |

## 表格的两个坑

第一，表头与正文之间**必须**有那行 `|---|---|`，否则整块会被当成普通文字；第二，表格前后要空一行，紧贴段落时有些解析器会把段落吃进表格。

## 代码围栏

```python
# 语言名写在围栏后面，用来做高亮
def normalize(x):
    return (x - x.mean()) / (x.std() + 1e-8)
```

行内码和中文之间**不加空格**也读得通（`docs/`目录），但加了空格排版更松快（`docs/` 目录）。本站统一用后者。

## 跨文档链接

直接写文件名，构建时会改写成站内渲染页地址：

- [文档库使用说明](文档库使用说明.md)
- [文档站改版记录](文档站改版记录.md)

## 命名约定

- 文件名以 `_` 开头、或叫 `README.md` 的文件**不进索引**，适合放草稿和说明
- 想固定网址路径就写 `slug`，否则沿用 `docs/` 下的相对路径
