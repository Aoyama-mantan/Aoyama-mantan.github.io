## 动机

RNN 沿时间步串行，长序列既慢又难并行，长程依赖还得靠隐状态一路带下来（梯度路径长）；CNN 能并行，但感受野要靠堆层数换。这篇的处理是：**把序列关系全部交给注意力**，不用循环也不用卷积——任意两个位置之间的路径长度变成 1。

## 缩放点积注意力

```
Attention(Q,K,V) = softmax( Q K^T / sqrt(d_k) ) V
```

那个 `sqrt(d_k)` 不是随手加的：若 `q`、`k` 各维独立、均值 0 方差 1，点积方差就是 `d_k`；`d_k` 一大，softmax 会被推进饱和区，梯度趋近 0。除以 `sqrt(d_k)` 把方差拉回 1。

**多头**是把表示切到 `h = 8` 个子空间分别做注意力再拼回：

```
MultiHead(Q,K,V) = Concat(head_1, ..., head_h) W^O
head_i           = Attention( Q W_i^Q , K W_i^K , V W_i^V )
```

每个头 `d_k = d_v = d_model / h = 64`，总计算量与单头同量级。

## 结构要点

| 部件 | 说明 |
|---|---|
| Encoder | 6 层，每层 = 自注意力 + 前馈，各自带残差与 LayerNorm |
| Decoder | 6 层，多一层对 encoder 输出的交叉注意力 |
| Mask | 解码端自注意力做因果掩码，防止看到未来 |
| 前馈 | 两层线性 + ReLU，`d_ff = 2048` |
| 位置编码 | 正弦/余弦，可与训练长度以外的位置对齐 |

```
PE(pos, 2i)   = sin( pos / 10000^(2i/d_model) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )
```

## 复杂度对比

| 层类型 | 每层复杂度 | 串行步数 | 最长路径 |
|---|---|---|---|
| 自注意力 | `O(n^2 d)` | `O(1)` | `O(1)` |
| 循环 | `O(n d^2)` | `O(n)` | `O(n)` |
| 卷积 | `O(k n d^2)` | `O(1)` | `O(log_k n)` |

短序列上循环更省，长序列注意力更优——代价是那项 `n^2`。

## 训练细节

- Adam，`beta_2 = 0.98`，学习率先预热再衰减：

```
lr = d_model^(-0.5) * min( t^(-0.5) , t * warmup^(-1.5) )
```

- 残差 dropout 0.1；标签平滑 `eps_ls = 0.1`（换来 BLEU 提升，但困惑度变差）
- 8 卡 P100 训 3.5 天；大模型 12 小时

> 结果：WMT14 EN-DE 28.4 BLEU，EN-FR 41.8 BLEU，训练成本远低于当时最好的循环模型。
